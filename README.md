# PV EL Power Loss Prediction

Reproducibility repository for the paper:

**From Correlation to Prediction: Electroluminescence-Based Indicators and Composite Health Scoring for Photovoltaic Power Loss Prediction in a 204-Panel Fleet**

## Overview

This repository provides the computational materials supporting the analysis presented in the manuscript. It contains the Python analysis scripts, feature definitions, model settings, validation procedures, and statistical analysis workflows used in the study.

The study investigates the relationship between electroluminescence (EL)-derived photovoltaic defect indicators and panel-level power loss, using a dataset comprising 204 PV panels.

## Contents

- Analysis scripts (Python)
- Feature definitions and data-processing procedures
- Statistical analysis procedures
- Machine-learning model settings
- Validation procedures
- Reproducibility information

## Software Requirements

The analysis was implemented in Python using the following packages:

- `pandas`
- `scikit-learn`
- `scipy`

## How to Reproduce the Analysis

1. Install Python and the required packages:
   - `pandas`
   - `scikit-learn`
   - `scipy`

2. Run the provided Python analysis scripts according to the workflow described in the manuscript.

3. The scripts implement the reported statistical analyses, machine-learning models, validation procedures, and sensitivity analyses.

## Data Availability

The raw panel-level dataset used in this study is not publicly released because it contains operational information associated with the inspected PV fleet.

The repository therefore provides the computational workflow and methodological details necessary to reproduce the analytical procedures without publicly distributing the raw operational dataset.

## Reproducibility

The analysis uses fixed random seeds where applicable to ensure reproducibility of the machine-learning and validation procedures.

The manuscript provides the definitions of the analysed features, model configurations, validation strategy, statistical procedures, and sensitivity-analysis settings.
